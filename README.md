## **A Userscript made to give i-ma'luum a dark mode appearance for easier and more comfortable viewing.**

![](https://i.postimg.cc/85VrnFdb/img-2026-10-21-14-32-03.png)

---

## How to use:

1. Install the Tampermonkey extension (or its alternatives) from the official website
2. Open Tampermonkey
3. Go to Utilities tab at the top-right corner
4. On the Import from file option, click "Browse...*
5. Upload the ima'luum-dark-mode.txt file
6. Click install
